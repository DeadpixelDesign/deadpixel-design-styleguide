# CodeBlock

The Code and Markdown view: Roboto Mono 16px / 1.4, `code-ink` (#F8F8F2) on `code-bg` (#2D2D2D), 16px padding, `radius-sm`. An optional header shows the file name or language and a Copy button.

- Provide: `code` (string), optional `filename`, `language` (adds `language-<lang>` for Prism or Shiki), `copyable` (default true).
- Long lines scroll inside the block; never wrap code.
- Keep blocks dark in both themes.
