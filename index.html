Foundations

The original style guide supplies the tokens, typefaces, themes, and interaction rules. Use tokens/tokens.json as the source of truth and tokens/tokens.css in the browser.

Spacing & layout

Use a 4px base scale: 4, 8, 12, 16, 24, 32, and 48px. The content container is 1200px wide with a 16px gutter. Use 16px inside cards and 24–48px between major groups.

Shape & elevation

Use 4px corners for controls and 8px for cards and alerts. Keep surfaces mostly flat; use the small shadow for raised menus and hover feedback.

Interaction

Controls need visible keyboard focus, meaningful labels, and at least 44px touch targets. Pair state colors with words or icons. Respect reduced motion.

Voice

Write in American English, sentence case, and active voice. Use direct verbs for actions and plain technical language. Show descriptive link text.

Typography

Raleway 700 is for headings, Nunito Sans for interface and body text, and Roboto Mono for code. Keep long reading at a 1.5 line height and around 65 characters per line.

Color

Brand blue and red are for marks and large headings. Use blue-text and red-text for body-size text; semantic colors carry information alongside labels. The Light, Dark, and System controls above preview the same token set.

Components

These live examples use the React component bundle. Each group includes its purpose, key options, and accessibility guidance. The API types are in components/index.d.ts.

Use the system

Load the token stylesheet before the component stylesheet, then load React 18, ReactDOM, and the bundle. Components are available on window.DeadPixel. Theme follows the device unless data-theme="light" or data-theme="dark" is set on the root element.

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="components/bundle.css">
<script src="https://cdnjs.cloudflare.com/ajax/libs/react/18.3.1/umd/react.production.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/react-dom/18.3.1/umd/react-dom.production.min.js"></script>
<script src="components/bundle.js"></script>
