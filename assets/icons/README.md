# Icons

Material Symbols Outlined, 24px, weight 400, unfilled, copied unchanged from https://github.com/google/material-design-icons (Apache License 2.0). Full catalog: https://fonts.google.com/icons.

- Each SVG uses a `0 -960 960 960` viewBox with a single path and no fill attribute, so as a plain `<img>` it renders black. In code, use the `Icon` component (inline SVG in `currentColor`), or inline the SVG and set `fill="currentColor"`.
- Starter set: home, search, menu, close, arrow_forward, arrow_back, open_in_new, link, check, add, info, warning, error, check_circle, content_copy, code, terminal, palette, mail, download, settings, grid_on.
- Need another icon: use its Material Symbols name with `Icon`; it loads from the icon font.
