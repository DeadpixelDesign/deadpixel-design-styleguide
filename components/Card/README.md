# Card

A `surface-alt` panel with `radius-md` for teasers: eyebrow (`label` style), Raleway title in `blue`, body in `body-long`, optional footer. With `href` the whole card is one link target and lifts with `shadow-sm` on hover, the title turning red.

- Provide: `title`, optional `eyebrow`, `children`, `footer`, `href`.
- Lay cards out in a grid with `space-4` gaps; no colored side borders.
