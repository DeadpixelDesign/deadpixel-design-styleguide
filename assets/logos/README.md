# Logos

- `deadpixel-skull.png`: the DeadPixel.Design pixel skull, full resolution (2181 × 2565, transparent edges). Colors: `pixel-mint`, `pixel-teal`, `pixel-magenta`, `pixel-void` and black. Use for print and large hero art.
- `deadpixel-skull-512.png`: the same mark at 512px wide for web headers, favicons source and social cards.
- Place on `pixel-void` or a dark `surface`. On light grounds, put it on a `pixel-void` panel. Never recolor or redraw it.
- No wordmark file exists yet: set "DeadPixel.Design" in Raleway 700 beside the mark.
