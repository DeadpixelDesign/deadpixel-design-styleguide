Foundations

The original style guide is the source for the visual language. Use tokens/tokens.json as the token source and load tokens/tokens.css before the component CSS.

Spacing

Use the 4px scale: 4, 8, 12, 16, 24, 32, 48px. Keep a 16px content gutter and give major groups room to breathe.

Shape

Use 4px corners for controls, 8px for cards and alerts. Reserve shadows for raised elements.

Interaction

Use visible labels and focus states. Pair status color with words, and respect reduced motion.

Voice

Write in sentence case and active voice. Use direct action labels and descriptive links.

Typography

Raleway 700 for headings, Nunito Sans for body and interface text, Roboto Mono for code. Long reading uses a 1.5 line height and about 65 characters per line.

Color

Brand blue and red are for large headings and marks. Use blue-text and red-text for smaller text. Theme tokens switch with the controls above or the device setting.

Components

These previews use semantic HTML and CSS. Native controls handle disclosure, and a small browser script handles the theme preview. The same classes work in Svelte, Vue, React, or server-rendered templates.

Actions & tags

Use primary for one main action, secondary for support, ghost for low emphasis. Tags are noninteractive metadata.

Frameworks

The CSS classes and semantic markup are the shared contract. Import the two stylesheets in your app and bind state using your framework. The existing React bundle remains an optional adapter.

Svelte / SvelteKit

<script>let count = 0;</script>
<button class="dp-btn dp-btn-primary"
  onclick={() => count++}>
  Clicked {count} times
</button>

Vue

<button class="dp-btn dp-btn-primary"
  @click="count++">
  Clicked {{ count }} times
</button>

React

<button className="dp-btn dp-btn-primary"
  onClick={() => setCount(count + 1)}>
  Clicked {count} times
</button>

See the repository README for complete setup and the framework adapters.
