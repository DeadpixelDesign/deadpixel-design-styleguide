# Link

Inline text link in `link` (`blue-text`), underlined, turning `link-hover` red on hover. Pass `external` to open in a new tab; it adds the `open_in_new` icon with an accessible "(opens in a new tab)" label.

- Provide: `href`, `children`, optional `external`.
- Always spell out URLs as the visible text when the address itself matters (for example https://deadpixel.design).
- Keep the underline: color alone does not mark a link.
